# Max Saga — mise à jour du site

Ce dossier contient :
- `index.html` : nouvelle page d'accueil complète ;
- `styles.css` : design ;
- `script.js` : menu mobile + année automatique ;
- `assets/max-saga-photo.jpg` : votre photo principale ;
- `assets/max-saga-logo.jpg` : logo Max Saga sans l'anneau extérieur.

## Installation dans GitHub
1. Ouvrir le dépôt `maxsaga.fr`.
2. Remplacer `index.html` par celui-ci.
3. Envoyer `styles.css` et `script.js`.
4. Dans le dossier `assets`, envoyer les deux images.
5. Ne pas supprimer `biographie.html`, `favicon.svg`, `robots.txt`, `sitemap.xml` ni `CNAME`.
6. Attendre quelques instants puis ouvrir https://maxsaga.fr/.

Le bouton « Voir la dernière vidéo » ouvre directement l'onglet Vidéos de la chaîne YouTube de Max Saga, où la vidéo la plus récente est affichée en premier. Cela évite de devoir modifier le site à chaque nouvelle publication.
