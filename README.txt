# Max Saga — site officiel

Fichiers prêts pour GitHub Pages.

## Mise en ligne
1. Ouvrir le dépôt GitHub qui publie `maxsaga.fr`.
2. Remplacer l'ancien `index.html` par celui-ci.
3. Envoyer aussi `styles.css`, `script.js`, `favicon.svg`, `robots.txt`, `sitemap.xml`, `CNAME` et le dossier `assets`.
4. Vérifier Settings → Pages : le domaine personnalisé doit rester `maxsaga.fr`.

Le site utilise uniquement HTML/CSS/JavaScript statiques, donc aucun hébergement supplémentaire n'est nécessaire.
